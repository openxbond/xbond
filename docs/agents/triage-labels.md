# 分診詞彙

skill 用五個固定角色談分診。本倉庫沒有 GitHub 標籤，角色字串直接寫在任務記錄頂部的 `分診：` 一行，與記錄自身的「狀態」欄是兩條不同的軸。

| skill 裏的角色    | 本倉庫寫法        | 含義                           |
| ----------------- | ----------------- | ------------------------------ |
| `needs-triage`    | `needs-triage`    | 待維護者評估                   |
| `needs-info`      | `needs-info`      | 等報告者補資訊                 |
| `ready-for-agent` | `ready-for-agent` | 已寫清，可交給無人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人工實現                   |
| `wontfix`         | `wontfix`         | 不處理                         |

若以後改用 GitHub Issues，這張表的第二欄就是實際要建立的標籤名。
