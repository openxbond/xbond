- اولین نسخهٔ رسمی کلاینت XBond برای Windows، macOS، Linux، Android، iOS، CLI، وب و Docker.
- هسته‌های داخلی mihomo و sing-box پیکربندی‌های Clash YAML و sing-box JSON را همان‌طور که هستند اجرا می‌کنند.
- پشتیبانی از اشتراک‌های شخص ثالث، اشتراک‌های حساب XBond Cloud و تاریخچهٔ نسخه‌های اشتراک با امکان بازگشت.
- سه حالت هدایت ترافیک: پروکسی سیستم، TUN و فقط پورت؛ وضعیت هسته، هدایت و اتصال خارجی جداگانه نمایش داده می‌شود.
- عیب‌یابی داخلی، تغییر سطح لاگ و پنج زبان رابط کاربری، به همراه فونت ایموجی رنگی داخلی در ویندوز.
- مشکل باقی‌ماندن رابط VPN اندروید پس از قطع اتصال و شروع با تأخیر سرویس سطح ماشین ویندوز که هدایت TUN را مختل می‌کرد برطرف شد.
