- 內嵌 mihomo 與 sing-box 雙核心，Clash YAML 與 sing-box JSON 配置可直接運行。

- 提供系統代理、TUN 與僅端口三種流量接管模式，核心、接管與外部連通狀態分開呈現。
- 內建診斷、日誌級別切換與五種介面語言，Windows 端為 emoji 內置彩色字體。
