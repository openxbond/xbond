- Android: 시트와 최상위 탭에서의 시스템 뒤로 가기 동작을 수정하고 햅틱 피드백과 환경설정을 연결했으며, 빈 허용 목록에서의 자가 트래픽 루프를 방지하고 Android 14+ 네트워크 전환 추적과 VPN 서비스 종료를 개선했습니다.
- Android: 사용하지 않던 로컬 컨트롤러 프록시 포트를 제거해 프로세스 내 루프백 보안을 강화했습니다.
- Windows: amd64 및 arm64용 `wintun.dll`을 아키텍처별로 제공하고 머신 서비스 디렉터리에서 추출하며, UAC 권한 상승 완료와 오류를 동기적으로 확인합니다.
- Windows: WinINet 시스템 프록시 변경을 즉시 브로드캐스트하고 로그오프 또는 종료 시 시스템 프록시를 복원하며, 제거 시 머신 서비스 파일을 완전히 정리합니다.
- 데스크톱: 패키징 빌드의 데몬 시작 경합 및 자동 복구를 수정하고 Windows 시작 프로그램 설정을 백그라운드 서비스와 동기화했으며, Linux 제거 시 자동 시작 항목을 정리합니다.
