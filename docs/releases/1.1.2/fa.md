- دسترسی مستقیم از مرورگر شبکه محلی به کنسول مدیریت Docker (مانند `http://<IP میزبان>:19090`) و نام‌های میزبان محلی (تک‌برچسبی و پسوندهای رزروشده مانند `.lan` و `.local`) پشتیبانی شد و هم‌زمان محافظت در برابر DNS rebinding برای دامنه‌های خارجی حفظ گردید.
- احراز هویت `XBOND_SECRET` برای کنسول مدیریت Docker و LocalAPI اضافه شد: هنگام تنظیم، توکن در HTML صفحه تزریق نمی‌شود و مرورگر پیش از دسترسی Secret را تأیید و به‌صورت محلی ذخیره می‌کند؛ در صورت تنظیم‌نشدن، دسکتاپ، موبایل و CLI محلی همچنان بدون رمز متصل می‌شوند.
- الگوهای پیش‌فرض Docker Compose و صفحه دانلود برای دسترسی شبکه محلی و پیکربندی `XBOND_SECRET` به‌روزرسانی شدند.
